# Elffuss AI

Task modules for the browser and the small sites built on them: background removal, OCR, object detection and depth maps, on WebGPU or WebAssembly. Every site runs its model in your browser. The only thing that is downloaded is the model, from its original Hugging Face repository at a pinned revision, and it is kept in this browser for the next visit.

This repository is being built. See `docs/` as it lands.

## En castellano

Módulos por tarea para el navegador y las webs pequeñas que los usan: quitar el fondo, leer texto, detectar objetos y mapas de profundidad, con WebGPU o WebAssembly. Cada web ejecuta su modelo en tu navegador. Lo único que se descarga es el modelo, desde su repositorio original de Hugging Face y fijado a una revisión; se descarga la primera vez y se guarda en este navegador.
